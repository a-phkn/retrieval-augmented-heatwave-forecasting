Notes:
- Reference floors: every model is judged against damped anomaly persistence (yesterday's standardised anomaly times a per-lead factor fitted on train), the strongest simple baseline here, not only against climatology and plain persistence.
- `anen_random -> anen` mostly measures the noise penalty of averaging 5 random past windows (climatology plus noise; a season-matched random control scores the same). The honest test of whether retrieved analogues help is `climatology -> anen`.
- delta = child - parent (negative = child better). 95% CI and p: cluster-jackknife t-test (`evaluation/stats.py`) with G year x season clusters and G-1 df. DM = Diebold-Mariano on seed-averaged per-window MSE (secondary; 'all' only). If they disagree, the cluster test is the headline.
- `*` = fewer than 10 clusters: the result is fragile. The val split (2016-18) only has 9 clusters, and 5 for the extreme stratum, so these are development diagnostics. Headline inference uses rolling-origin folds.
- Seeds (p/c): persistence and climatology are deterministic (1 'seed'); only a neural model's seed variance enters the SE when compared with them.
- Optimistic for the neural models: both were early-stopped on this same val split, so their val errors are slightly favourable relative to the baselines.
- Known v1 limitation: `models/retrieval_lstm.py` spreads attention uniformly over zero-padded slots when a query has no eligible analogue (163/13,131 train windows; no val windows). RA-v1 is kept as originally built; the fix belongs to the v2 retrieval model.
